현재 로컬 Catch2 호환 헤더가 `TEST_CASE("name", "[tag]")`와 `FAIL()`을 아직 지원하지 않습니다. 테스트 파일에는 헬퍼를 두지 않고, 헤더 매크로만 Catch2 예시 형태를 컴파일할 수 있게 보강하겠습니다.

이제 테스트 파일 자체를 전부 순수 RED 선언으로 바꿉니다. 각 테스트는 Given-When-Then 주석과 변환 비율만 포함하고, 별도 메소드나 실행 로직 없이 `FAIL("RED")`로 고정하겠습니다.

테스트 파일에서 모든 별도 메소드와 실행 로직을 제거했습니다. 이제 컴파일만 확인해서 RED 테스트 소스가 빌드는 통과하는지 보겠습니다.

수정했습니다.

`tests/test_unit_converter_red.cpp`에서 별도 메소드/헬퍼/실행 로직을 모두 제거하고, 요청 예시처럼 각 테스트를 순수 RED 형태로 바꿨습니다.

```cpp
TEST_CASE("test_normal_meter_to_feet_returns_expected", "[domain][red]") {
    // Given ...
    // When ...
    // Then ...
    FAIL("RED");
}
```
