## 3. 주요 구현 범위

### 3.1 Domain Logic

`cpp/UnitConverter.cpp`에 다음 Domain 기능을 구현했다.

| 기능 | 구현 내용 |
|---|---|
| 기본 단위 등록 | `resetDefaultUnits()`로 `meter`, `feet`, `yard` 기본 레지스트리 구성 |
| 비율 상수화 | `kMeterToFeet`, `kMeterToYard` 상수 정의 후 역비율 계산 |
| 단일 변환 | `convert(fromUnit, value, toUnit)` 구현 |
| 전체 변환 | `convertAll(fromUnit, value)` 구현 |
| 동적 단위 등록 | `registerUnit(unit, rateToMeter)` 구현 |
| 설정 로드 | JSON/YAML 형태의 `name`, `rateToMeter` 로드 구현 |
| 기본값 유지 | 없는 설정 경로는 `false` 반환, 기존 기본 비율 유지 |

### 3.2 Boundary Layer

Boundary 책임으로 다음 기능을 구현했다.

| 기능 | 구현 내용 |
|---|---|
| 입력 파싱 | `parseInput("unit:value")` 구현 |
| 형식 검증 | 콜론 없음/복수 콜론 입력은 `INVALID_FORMAT` |
| 값 검증 | 빈 값, 숫자 파싱 실패, trailing text는 `INVALID_VALUE` |
| 음수 검증 | 음수 입력은 `NEGATIVE_VALUE` |
| 단위 검증 | 미등록 단위는 `UNKNOWN_UNIT` |
| 유스케이스 조합 | `handleInput()`에서 파싱 후 전체 변환 수행 |
| Plain 출력 | `formatPlain()` 구현 |
| JSON 출력 | `formatJson()` 구현 |

### 3.3 main 함수 정리

`main()`에는 직접 변환 분기와 비율 계산을 남기지 않았다.

현재 `main()`은 다음 책임만 가진다.

- 기본 단위 초기화
- 콘솔 입력 수신
- `handleInput()` 호출
- `formatPlain()` 출력
- 예외 메시지 출력 및 종료 코드 반환
