# UnitConverter_05 Golden Master / ApprovalTests 적용 보고서

## 1. 개요

본 보고서는 `UnitConverter_05` 프로젝트에 출력 기반 Golden Master 회귀 안전장치를 구축하고, 이후 `ApprovalTests.cpp` 라이브러리 기반 승인 테스트로 전환한 작업 내용을 정리한다.

작업 목적은 리팩터링 전후 `UnitConverter` 콘솔 출력의 관찰 가능한 동작을 고정하여, 변환 비율·출력 포맷·시나리오별 결과 변경을 회귀로 탐지하는 것이다.

## 3. Golden Master 기준 출력

초기 기준 파일로 `tests/golden_master_expected.txt`를 생성했다.

기준 시나리오는 다음 4개다.

| TC | 입력 | 검증 목적 |
|---|---|---|
| GM-TC-01 | `meter:2.5` | meter 기준 feet/yard 변환 출력 고정 |
| GM-TC-02 | `feet:1.0` | feet 기준 meter/yard 변환 출력 고정 |
| GM-TC-03 | `yard:1.0` | yard 기준 feet/meter 변환 출력 고정 |
| GM-TC-04 | `meter:0.0` | 0 경계값 출력 고정 |

`tests/golden_master_expected.txt` 내용:

```text
[meter:2.5]
2.5 meter = 8.202100 feet
2.5 meter = 2.734025 yard
---
[feet:1.0]
1 feet = 0.304800 meter
1 feet = 0.333332 yard
---
[yard:1.0]
1 yard = 3.000009 feet
1 yard = 0.914403 meter
---
[meter:0.0]
0 meter = 0.000000 feet
0 meter = 0.000000 yard
```

해당 파일은 요청에 따라 `git add tests/golden_master_expected.txt` 대상으로 포함했다.

## 4. 출력 포맷 안정화

Golden Master 문자열 비교가 안정적으로 동작하도록 `cpp/UnitConverter.cpp`의 plain 출력 포맷을 정리했다.

주요 변경:

- 변환 결과값을 `std::fixed << std::setprecision(6)`로 고정
- 입력 source 값은 기존 표현을 유지하도록 `std::defaultfloat` 적용
- stdout 캡처를 오염시키지 않도록 입력 프롬프트를 `std::cout`에서 `std::cerr`로 이동

이 변경으로 다음과 같은 출력이 안정적으로 생성된다.

```text
2.5 meter = 8.202100 feet
2.5 meter = 2.734025 yard
```

## 6. 수동 Approve 패턴 구현 이력

초기 `tests/test_golden_master.cpp`는 다음 approve 패턴으로 작성했다.

- 기준 파일이 없으면 현재 actual 출력으로 자동 생성
- 기준 파일이 있으면 `std::ifstream`으로 expected/actual 문자열 비교
- 불일치 시 line-by-line diff 출력 후 테스트 FAIL
- CMake에 `add_test(NAME GoldenMaster COMMAND UnitConverter_test)` 등록

이후 사용자 요청에 따라 수동 diff/비교 구현을 제거하고 `ApprovalTests.cpp` 기반으로 재작성했다.

## 7. ApprovalTests.cpp 적용

최종 `tests/test_golden_master.cpp`는 `ApprovalTests.cpp`를 사용한다.

핵심 구조:

```cpp
#define APPROVALS_CATCH
#include "ApprovalTests.hpp"

auto approvalDirectoryDisposer =
    ApprovalTests::Approvals::useApprovalsSubdirectory("approval_tests");
```

stdout 캡처 방식:

```cpp
UnitConverter < input.txt > actual.txt
```

승인 비교 방식:

```cpp
ApprovalTests::Approvals::verify(
    actual, ApprovalTests::Options().fileOptions().withFileExtension(".txt"));
```

테스트 케이스:

```cpp
TEST_F(GoldenMasterTest, UnitConverter_meter_2_5)
TEST_F(GoldenMasterTest, UnitConverter_feet_1_0)
TEST_F(GoldenMasterTest, UnitConverter_yard_1_0)
TEST_F(GoldenMasterTest, UnitConverter_meter_0_0)
```

`TEST_F`는 프로젝트가 Catch2 기반이므로 Catch2 `TEST_CASE`에 매핑하는 호환 매크로로 제공했다.

## 8. Approval 기준 파일

ApprovalTests.cpp 표준 구조에 맞춰 다음 승인 파일을 추가했다.

| 입력 | 승인 파일 |
|---|---|
| `meter:2.5` | `tests/approval_tests/test_golden_master.GoldenMasterTest.UnitConverter_meter_2_5.approved.txt` |
| `feet:1.0` | `tests/approval_tests/test_golden_master.GoldenMasterTest.UnitConverter_feet_1_0.approved.txt` |
| `yard:1.0` | `tests/approval_tests/test_golden_master.GoldenMasterTest.UnitConverter_yard_1_0.approved.txt` |
| `meter:0.0` | `tests/approval_tests/test_golden_master.GoldenMasterTest.UnitConverter_meter_0_0.approved.txt` |

ApprovalTests.cpp는 실패 시 `.received.txt`를 생성하고 `.approved.txt`와 비교한다. 현재 검증 후 남아 있는 `.received.txt` 파일은 없다.

## 9. CMake 연동

`CMakeLists.txt`에 `FetchContent` 기반 ApprovalTests.cpp 연동을 추가했다.

주요 내용:

```cmake
include(FetchContent)

set(APPROVAL_TESTS_BUILD_TESTING OFF CACHE BOOL "" FORCE)
set(APPROVAL_TESTS_BUILD_EXAMPLES OFF CACHE BOOL "" FORCE)
set(APPROVAL_TESTS_BUILD_THIRD_PARTY_CATCH2 ON CACHE BOOL "" FORCE)
FetchContent_Declare(
    ApprovalTestsCpp
    GIT_REPOSITORY https://github.com/approvals/ApprovalTests.cpp.git
    GIT_TAG master
)
FetchContent_MakeAvailable(ApprovalTestsCpp)
```

Golden Master 테스트 타깃:

```cmake
add_executable(UnitConverter_test tests/test_golden_master.cpp)
target_link_libraries(UnitConverter_test PRIVATE ApprovalTests::ApprovalTests)
add_test(NAME GoldenMaster COMMAND UnitConverter_test)
```

Windows/MSVC 환경에서 ApprovalTests.cpp의 Catch2 연동 헤더가 `catch2/catch.hpp`를 요구하여, ApprovalTests.cpp가 제공하는 Catch2 include 경로를 `UnitConverter_test`에 추가했다.
